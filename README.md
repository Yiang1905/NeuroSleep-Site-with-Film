# NeuroSleep — Adaptive Sleep System Concept

## Project status
NeuroSleep is a concept-stage project exploring sleep-position sensing, adjustable neck support, and a connected digital experience. The current preferred transaction is an overall transfer of the project and its transferable assets.

## Current assets

- Concept film and media files
- Product concept and preliminary system-architecture direction
- Brand, positioning, and commercialization materials
